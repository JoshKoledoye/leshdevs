# leshdevs

A minimal React + Vite scaffold for the Leshdevs app.

## Scripts

- `npm install`
- `npm run dev`
- `npm run build`

## Vercel

This project is set up to deploy cleanly on Vercel using the standard Vite app conventions.

## Notes

This is only the initial scaffold. The app structure is ready to expand into:
- career path exploration
- concept walkthrough pages
- roadmap visualization
- quiz gameplay and leaderboard logic
